### 📆 Day 020: Dijkstra's Algorithm Fundamentals
- **Phase:** Phase 1: Graphs & State Search (Days 001–040)
- **Time Budget:** ~1.5–2 hours/day (`Track A`: ~65m | `Track B`: ~25m)

### 📆 Day 193: Fenwick Tree (BIT)
- **Phase:** Phase 10: Advanced DS & Final Mocks (Days 191–200)
- **Time Budget:** ~1.5–2 hours/day (`Track A`: ~65m | `Track B`: ~25m)
- **Track A (New Learning — Graphs & Advanced DSA):**
  - **Theory & Pattern:** Fenwick Tree (BIT): uses lowbit trick `i & (-i)` to compute prefix sums in O(log N). Update: add delta to index, propagate upward via `i += i & (-i)`. Query prefix sum: accumulate values, move downward via `i -= i & (-i)`. Simpler than Segment Tree but limited to prefix queries.
  - **C++ Focus:** `void update(int i, int delta) { for(; i<=n; i += i & (-i)) bit[i] += delta; } int query(int i) { int sum = 0; for(; i>0; i -= i & (-i)) sum += bit[i]; return sum; } int rangeQuery(int l, int r) { return query(r) - query(l-1); }`
  - **Target Problems:**
    - [ ] LC 315 Count of Smaller Numbers After Self (BIT)
    - [ ] LC 308 Range Sum Query 2D - Mutable
