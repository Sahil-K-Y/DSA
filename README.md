This repository contains the complete, battle-tested **200-Day DSA Master Curriculum** crafted specifically for **Sahil Kumar (Sky)**.

To eliminate time wastage and avoid restarting from scratch, this repository enforces a **Graph-First Dual-Track Framework**:

1. **Graph-First Progression (Track A):** Jumping directly into Graphs builds mental models for recursion, state traversal, and backtracking early on, rendering complex Dynamic Programming and Tree patterns far more intuitive.
2. **Guided Daily Spaced Revision (Track B):** A 15-slot rotating schedule ensures that every day includes a **2-minute C++ Code & Theory Syntax Guide** and 1 dedicated revision problem for past topics (Arrays through BST). Memory decay is completely eliminated.

## 🧠 Execution System & Daily Workflow (~90–120 mins)

```
  1️⃣ THEORY & SYNTAX (15-20 MINS)
     Read core intuition, algorithm flow, and time/space complexity bounds.

  2️⃣ C++ SCRATCH IMPLEMENTATION (20-25 MINS)
     Code the foundational template/data structure in C++ without referencing notes.

  3️⃣ TRACK A TARGET LEETCODE (40-50 MINS)
     Solve 1–2 new target problems cold during a 25-minute strict timer window.

  4️⃣ TRACK B REVISION REFRESH (20-25 MINS)
     Read the 2-minute C++ Syntax & Theory Guide, then solve the assigned revision problem.
```

### 🚦 Problem Status Badges
- ⬜ **`Unseen`** — Problem not attempted yet
- 🟡 **`Hinted`** — Solved with editorial/hints (scheduled for cold retry within 24–72 hrs)
- 🟢 **`Cold`** — Solved independently without hints
- 🔴 **`Repair`** — Failed cold retry, requires structured concept review

### 🗂️ Solution Organization Convention

Every C++ solution lives under: **`<Topic>/<DayNumber>/<Descriptive_Name>.cpp`**

- **`<Topic>/`** — Top-level folder named after the phase's core topic (e.g. `Graph/`; future phases add `Heap/`, `Greedy/`, `Backtracking/`, `DP/`, etc.)
- **`<DayNumber>/`** — Sub-folder matching the day number in [`roadmap_v3.txt`](roadmap_v3.txt) (e.g. `1/` ↔ *Day 001*)
- **`<Descriptive_Name>.cpp`** — Snake_Case filename describing the concept or problem solved that day

### ⚙️ Compiling & Running a Solution

```bash
g++ -std=c++17 Graph/1/Adjacency_Matrix_vs_Adjacency_List_vs_Edge_List.cpp -o sol
./sol
```

> Compiled binaries (`*.exe`, `*.out`, `*.o`) are git-ignored — only source `.cpp` files are committed.
