## 🎯 The Philosophy: Why "Graph-First"?

After solving 200+ problems sequentially, I realized the standard Array → String → Linked List path often builds a **hint-dependency**. To break this plateau, I designed the **Graph-First Dual-Track Framework**. 

By starting with complex, interconnected structures like **Graphs and Trees**, the brain is forced to master **DFS, BFS, and Recursion** immediately—making dynamic programming, backtracking, and array patterns feel highly intuitive later on.

## 🧭 Daily execution system
1. **10–15 min recall:** previous template/use-case/complexity from memory.
2. **Track A (60–90 min):** new topic theory → dry run → scratch C++ implementation → 1–2 core problems.
3. **Track B (25–40 min):** one rotating old-topic revision slot. Use fresh/RED/YELLOW problems; don't repeat GREEN problems forever.
4. **Pattern Recognition:** write **Input Signal → Question Signal → Constraint Signal** before choosing an approach.
5. **No-hint window:** 25–30 minutes. If a hint/editorial is used, mark 🟡 and reattempt after 24–72h, then again after ~7 days.
6. **Interview gate:** after each major phase, solve 2 blind questions, reattempt 1 hinted question cold, and explain 1 problem aloud.
7. **Status:** ⬜ Unseen | 🟡 Learned with help | 🟢 Cold | 🔴 Repair.
8. **Daily mandatory load:** Track A ka **first listed core problem mandatory**. Track A ka second/extra problem bonus unless the day explicitly says both are core.
9. **Track B load:** Sirf **first due/cold revision problem mandatory**. Second problem bonus/backup.
10. **Duplicate control:** Agar same problem Track A aur Track B mein aa jaye, duplicate solve mat karo; Track B se next due 🔴/🟡 problem uthao.
11. **Platform fallback:** Exact LeetCode problem unavailable/Premium ho to GFG, TUF ya Coding Ninjas equivalent valid hai.
12. **Completion evidence:** Topic tabhi complete maana jayega jab theory recall + dry run + accepted/tested C++ + time/space complexity + status update ho.
13. **Missed-day rule:** Calendar chase mat karo. Missed day ke baad next sitting se wahi roadmap day continue karo; 2–3 days ko ek din mein compress mat karo.
14. **Hint rule:** 25–30 min genuine attempt ke baad hint allowed. Hint/editorial ke baad problem 🟡 rahega jab tak 24–72h ke baad cold reattempt successful na ho.
15. **Interview-readiness rule:** Phase gate pass kiye bina next major phase ko blindly rush mat karo; weak items ko 🔴/🟡 queue mein rakho.
