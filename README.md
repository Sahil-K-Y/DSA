## 🚦 Daily Execution & Logging Rules

1. **Theory First:** Understand intuition, time/space complexity, and pattern signals visually before coding.
2. **C++ Scratch Implementation:** Code data structures and templates from scratch without STL shortcuts first.
3. **25-Min Cold Window:** Attempt every problem independently without hints.
4. **Status Tracking:**
   - ⬜ `Unseen` — Not attempted yet
   - 🟡 `Hinted` — Solved with editorial (scheduled for cold retry)
   - 🟢 `Cold` — Solved independently without hints
   - 🔴 `Repair` — Failed cold retry, structured review required
